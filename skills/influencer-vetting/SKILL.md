# 达人合作筛选

## 适用场景
选择海外社媒达人（TikTok、Instagram、YouTube）进行种草或带货，比较多位候选人的报价与效果。

## 输入信息
- 品牌目标市场、目标人群画像、产品定价与卖点
- 达人主页数据：粉丝数、近 20 条内容的播放与互动数据、粉丝地域与年龄分布（如平台提供）
- 报价单与合作形式（图文、短视频、直播、联盟佣金）
- 历史合作案例（如有）

## 评估步骤
1. **真实性检查**：互动率异常（如点赞远高于评论、粉丝增长突变）时标记为风险，建议人工核查粉丝质量。
2. **受众匹配**：目标人群占粉丝比例、地域与购买力是否与市场吻合。
3. **内容适配**：过往内容风格与品牌调性是否一致，是否有同品类竞品合作。
4. **互动率计算**：（点赞 + 评论 + 收藏 + 转发）÷ 播放或粉丝数，按内容类型分别计算。
5. **报价合理性**：按每千次有效曝光成本（CPM）和带货佣金测算，与历史基准对比。
6. **综合评分与合作建议**：给出推荐、备选或不推荐结论，并列出合作条款的关键点（授权范围、发布时间、修改次数、数据回传）。

## 输出格式
```
## 候选人评分表（匹配度 | 真实性 | 互动率 | 内容适配 | 报价 | 总分）
## 风险提示（粉丝质量、过往合作争议等）
## 推荐结论与理由
## 合作条款要点
## 合作邀约邮件草稿
```

## 注意事项
- 所有数据需由达人或平台后台提供并注明来源，不得臆造粉丝数或转化数据。
- 合作条款须明确广告标识要求（如 #ad、平台品牌合作功能），符合各国广告法规。
- 不承诺带货效果。
