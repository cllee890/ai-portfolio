# 平台合规审核

## 适用场景
商品上架前自查、被平台下架或审核驳回后的整改、批量检查已上架商品。

## 输入信息
- 目标平台与站点（如 Amazon US、Shopee SG、TikTok Shop ID）
- 商品标题、五点描述、详情页文案、主图与场景图说明
- 类目、品牌、是否有认证证书或检测报告
- 平台返回的驳回原因（如有）

## 审核维度
1. **违禁与敏感词**：绝对化用语（"最好""第一""100%有效"）、医疗或功效宣称、政治与宗教敏感表述。
2. **夸大与虚假宣传**：无依据的数据、无法证明的对比、"限时免费"等与实际不符的承诺。
3. **知识产权**：使用他人品牌名、型号、Logo 或未授权图片；疑似仿品描述。
4. **类目与资质**：需要认证的类目（如电子产品 FCC/CE、儿童用品、食品、化妆品）是否提供证明。
5. **图片规范**：主图背景、文字覆盖、水印、尺寸与平台要求是否一致。
6. **描述一致性**：标题、详情页、规格参数之间是否互相矛盾。

## 输出格式
```
## 审核结论（通过 / 需整改 / 高风险）
## 问题清单
| 位置 | 原文 | 风险类型 | 风险等级 | 整改建议 |
## 需补充的资质材料
## 整改后文案示例
## 需人工确认的事项（平台规则可能更新，以后台最新规则为准）
```

## 注意事项
- 平台规则变化频繁，结论需提示用户对照平台最新政策核实。
- 不替代法律意见；涉及商标或专利纠纷时，建议咨询专业律师。
- 整改建议应保留原意，不得通过改写规避审核。
