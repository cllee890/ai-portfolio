# 短视频脚本与分镜

## 适用场景
新品种草、详情页视频、达人拍摄提纲、广告素材制作前的脚本设计。

## 输入信息
- 产品名称、核心卖点（最多 3 条）、价格与促销信息
- 目标市场与语言、目标人群
- 视频时长（建议 15 秒、30 秒、60 秒三档）
- 可用素材：实拍镜头、产品图、已有达人内容

## 脚本结构
1. **前 3 秒钩子**：提出痛点或反常识结论，配合强视觉冲击。
2. **问题与场景**：用 3–5 秒展示使用场景，引起共鸣。
3. **卖点演示**：每个卖点对应一个镜头，直接展示效果而非仅口头描述。
4. **社会证明**：评价截图、使用前后对比（需真实）、销量数据（需可核实）。
5. **行动号召**：明确下一步（点击购物车、限时优惠），并与平台可用的促销形式一致。

## 输出格式
```
## 视频目标与平台
## 分镜表（时间 | 画面 | 镜头类型 | 字幕 | 旁白/配乐建议）
## 完整旁白脚本（目标语言 + 中文译文）
## 封面与标题建议（3 个备选）
## 拍摄清单（道具、场地、需要的达人或模特）
## 合规提示（广告标识、功效宣称、版权音乐）
```

## 注意事项
- 不使用无法证明的功效宣称，如"三天见效""永久根治"。
- 使用音乐、字体与素材前需确认版权授权。
- 脚本仅为创作建议，发布前需按平台规则审核。
