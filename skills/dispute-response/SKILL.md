# 平台纠纷与拒付应对

## 适用场景
平台介入的买家纠纷、信用卡拒付（chargeback）、物流异常引发的争议、质量或描述争议。

## 输入信息
- 订单号、下单时间、付款金额与币种、商品信息
- 买家提出的理由与时间线（留言、邮件、工单）
- 物流轨迹、签收记录、发货凭证、商品照片与质检记录
- 平台或支付机构给出的纠纷类型与截止时间

## 处理步骤
1. **识别纠纷类型**：未收到货、与描述不符、质量问题、重复扣款、拒付。
2. **时限检查**：标出申诉截止日期，超期即无法申诉的情况需优先提醒。
3. **证据矩阵**：每类纠纷对应所需证据（如未收到货需物流签收轨迹；与描述不符需详情页截图与实物照片）。
4. **事实梳理**：按时间线列出关键事件，区分已确认事实与待核实事项。
5. **回复策略**：证据充分时据理申诉；证据不足时评估部分退款或退货的成本，给出止损建议。
6. **撰写回复**：语气专业、简洁，只陈述可核实的事实，附证据编号。

## 输出格式
```
## 纠纷概要（类型 | 金额 | 截止时间 | 风险等级）
## 时间线
## 证据清单（编号 | 证据 | 来源 | 是否已具备）
## 申诉理由与策略建议
## 回复话术（平台留言 / 支付机构申诉）
## 升级与止损方案
```

## 注意事项
- 不编造物流轨迹、签收记录或买家沟通内容，缺失证据须明确列出。
- 回复应以事实为依据，不得使用威胁、误导或诱导买家撤诉的表述。
- 拒付金额较大或涉及法律责任时，建议咨询专业人士。
