# 独立站网站审计

## 适用场景
独立站上线前检查、流量下滑排查、转化率低的诊断、季度体检。

## 输入信息（缺失时向用户询问）
- 站点 URL、主要市场与语言、主营品类
- 目标指标（如转化率、自然流量、客单价）
- 可选：GA4/Search Console 数据、现有页面清单

## 审计流程
1. **技术层**：HTTPS、robots.txt、sitemap.xml、canonical、404/301 链路、移动端适配
2. **性能层**：LCP/CLS/INP、图片体积与懒加载、第三方脚本数量
3. **SEO 结构**：Title/Meta 唯一性与长度、H1 结构、内链深度、面包屑、结构化数据（Product/FAQ/Review）
4. **转化路径**：首页→类目→商品→购物车→结算的步骤数、CTA 可见性、信任元素（退换货、支付方式、物流时效）
5. **合规层**：隐私政策、Cookie 授权、目标市场法规（如 GDPR）、退换货与税费说明
6. **多语言/多市场**：hreflang、货币与语言切换、本地化支付

## 输出格式
```
## 审计摘要（总分 x/100）
## 高优先级问题（影响收入或排名，立即处理）
| 问题 | 位置/证据 | 影响 | 建议 | 预估工作量 |
## 中优先级问题
## 低优先级优化
## 下一步 30 天行动计划
```

## 注意事项
- 每条结论需附可验证的证据（URL、截图或数据），不凭空推断。
- 无法访问的页面或数据需明确标注"未检查"。
