# 物流渠道比较

## 适用场景
新市场开拓、运费大幅上涨、退货率高、签收投诉集中等需要重新选择渠道的情况。

## 输入信息
- 目的国与邮编段、商品重量与体积（含包装）、单票货值
- 候选渠道报价（按首重、续重、燃油费、附加费拆分）
- 各渠道近 90 天的时效、签收率、丢件率数据（如无数据需注明为估计）
- 退货政策与逆向物流成本

## 计算步骤
1. **计量重量**：实重与体积重取较大值，按渠道规则计算（如 体积 ÷ 5000 cm³/kg）。
2. **单件总成本** = 运费 + 燃油费 + 附加费 + 关税代付（如适用）+ 丢件赔付期望值（丢件率 × 货值）。
3. **有效成本**：计入签收失败的二次派送与退货成本（退货率 × 逆向运费）。
4. **时效评分**：按承诺时效与实际达成率综合评估。
5. **选择建议**：按品类（轻小件、大件、高货值、易碎品）给出首选与备选渠道，并列出切换阈值。

## 输出格式
```
## 假设与数据来源
## 渠道成本对比表（实重 | 计费重 | 运费 | 附加费 | 丢件期望 | 有效成本）
## 时效与签收率对比
## 分品类推荐（首选 / 备选 / 不推荐）
## 切换阈值与风险提示
```

## 注意事项
- 报价与附加费政策经常调整，结论需标注报价日期。
- 丢件率、签收率若缺少真实数据，应明确标注为估计值，不能当作事实。
- 关税与清关规则因国家而异，涉及时建议以物流商书面说明为准。
