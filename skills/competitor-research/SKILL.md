# 竞品研究

## 适用场景
选品前验证市场、新站/新品定位、竞品动态跟踪、定价策略参考。

## 输入信息
- 目标市场与品类
- 竞品列表（3–5 个为宜，含网站或商店链接）
- 我方产品/站点信息（用于对比）

## 研究维度
| 维度 | 关注点 |
|---|---|
| 定位 | 目标人群、价值主张、品牌调性 |
| 商品 | SKU 数量、爆品结构、组合/套装策略 |
| 价格 | 售价、折扣节奏、运费与门槛 |
| 流量 | 渠道占比（自然/付费/社媒/联盟）、主要关键词 |
| 内容 | 详情页结构、视频/评测、FAQ 与信任元素 |
| 评价 | 好评/差评高频词、痛点与未满足需求 |
| 营销 | 活动节奏、会员/积分、社媒投放素材 |

## 输出格式
```
## 市场概览（规模、增速、季节性，注明数据来源）
## 竞品对比矩阵
## 竞品优劣势 SWOT（每家一段）
## 差异化机会（3 条，按可行性排序）
## 风险提示
```

## 注意事项
- 区分"已确认事实"与"推断"。流量、销量等第三方估算需标注工具与日期。
- 不抓取或使用竞品的非公开数据。
