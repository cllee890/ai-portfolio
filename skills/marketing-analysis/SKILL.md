# 营销数据分析

## 适用场景
周/月度复盘、大促效果评估、渠道对比、销售异常诊断。

## 输入信息
- 时间范围与对比基准（环比/同比）
- 数据：订单、流量（GA4 或平台后台导出）、广告花费、退款数据
- 业务目标（GMV、利润、新客数等）

## 分析框架
1. **指标拆解**：GMV = 访客数 × 转化率 × 客单价；利润 = 收入 − 商品成本 − 物流 − 平台费 − 广告费 − 退款。
2. **渠道分析**：各渠道访客、转化率、ROAS、新客占比。
3. **用户分析**：新老客比例、复购率、首单到二单周期。
4. **归因与异常**：先核对数据口径，再判断是季节、投放、价格、库存还是竞品变化导致。
5. **建议**：每条建议对应一个指标与预期影响，并标注优先级。

## 输出格式
```
## 核心结论（3 条以内）
## 指标概览（本期 / 对比期 / 变化率）
## 驱动因素拆解
## 行动建议（动作 | 负责指标 | 预期影响 | 优先级）
## 数据口径说明与局限
```

## 注意事项
- 相关不等于因果，结论需注明证据强度。
- 样本量过小时不做显著性判断。
