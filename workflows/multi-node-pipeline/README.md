# 多节点串联工作流：选品 → 文案 → 质检 → 发布

## 目标
将"竞品数据抓取 → 标题生成 → 合规检查 → 人工确认 → 发布 API"串联为一条可复用流水线。

## 节点设计
| 节点 | 类型 | 输入 | 输出 | 失败处理 |
|---|---|---|---|---|
| N1 数据输入 | 表单/Excel | 商品属性 | JSON | 字段缺失则终止 |
| N2 竞品参考 | HTTP 工具 | 关键词 | 竞品标题列表 | 超时重试 2 次 |
| N3 文案生成 | LLM（模板 prompts/industry-prompt-templates.md） | N1+N2 | 标题/卖点 JSON | 解析失败回退重试 |
| N4 合规检查 | LLM + 规则词表 | N3 | 风险等级 | 高风险进入人工 |
| N5 人工确认 | 审批节点 | N4 | 通过/修改 | 超时提醒 |
| N6 发布 | HTTP API | N5 | 商品ID | 幂等键防重复 |

## 关键实现要点
- 每个节点输出统一 JSON Schema，便于替换模型。
- 变量与密钥放入环境变量或平台凭证库，不写入流程文件。
- 节点日志记录耗时、token 数与错误码，便于排查。
