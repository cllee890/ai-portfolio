# 广告投放效果分析

## 适用场景
日常投放巡检、周/月复盘、ROAS 下滑诊断、素材疲劳判断、预算扩量决策。

## 输入信息
- 广告平台导出数据（花费、展示、点击、转化、转化价值）
- 时间范围、盈亏平衡 ROAS
- 近期变更记录（出价、预算、素材、落地页）

## 诊断漏斗
| 层级 | 指标 | 异常说明 |
|---|---|---|
| 曝光 | CPM | 上升多为竞争加剧或受众过窄 |
| 点击 | CTR | 低于基线说明素材/受众吸引力不足 |
| 转化 | CVR | 低于基线多为落地页或价格问题 |
| 收益 | ROAS / CPA | 综合判断，结合客单价与退款 |

## 决策规则（示例，需按账户调整）
- **扩量**：ROAS 连续 7 天高于目标 ROAS 且花费稳定 → 逐步提高预算（每次不超过 20%）。
- **优化**：CTR 低 → 换素材；CVR 低 → 查落地页与结算流程。
- **停投**：花费超过 2–3 倍 CPA 目标仍无转化 → 暂停。
- **疲劳**：频次持续上升且 CTR 下降 → 更新素材。

## 输出格式
```
## 总体表现（花费、ROAS、CPA，对比目标）
## 分渠道/系列/素材排名
## 异常诊断（现象 → 可能原因 → 验证方法）
## 行动清单（动作 | 对象 | 预期 | 复查时间）
```

## 注意事项
- 归因窗口与平台口径不同，需说明对比基准。
- 小样本数据不做结论，建议等待足够转化量。
