## 一、工作范围与对应目录

| 能力方向 | 内容 | 目录 |
|---|---|---|
| 复杂工作流 | 多节点串联、图像流开发、插件开发、API 对接 | `workflows/` |
| Prompt 工程 | 行业定制提示词、输出格式规范优化 | `prompts/` |
