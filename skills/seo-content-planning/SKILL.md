# SEO 内容策划

## 适用场景
独立站博客规划、类目页/导购页内容补充、季节性内容排期、多语言内容本地化。

## 输入信息
- 站点主营品类、目标市场与语言
- 现有文章与页面列表（如有）
- 目标关键词或业务优先级

## 策划流程
1. **关键词主题簇**：以一个核心词为 Pillar 页，拆分出购买意图、比较、教程、问题类长尾词作为 Cluster。
2. **搜索意图匹配**：信息型 → 教程/指南；商业型 → 对比/评测；交易型 → 类目/商品页。
3. **内容日历**：按月排期，标注季节节点（如黑五、开学季）与发布节奏。
4. **文章大纲**：H1/H2/H3 结构、必答问题（FAQ）、内链锚文本、CTA。
5. **内链规划**：Pillar 与 Cluster 双向链接，商品页回链相关文章。

## 输出格式
```
## 主题簇总览（Pillar + Cluster 表格：关键词 | 意图 | 页面类型 | 优先级）
## 30 天内容日历
## 单篇文章大纲示例（含 Meta Title / Description 草稿）
## 内链计划
```

## 注意事项
- Meta 标题控制在约 60 字符以内，描述约 155 字符以内。
- 内容需原创且有实际价值，避免批量生成的低质页面。
