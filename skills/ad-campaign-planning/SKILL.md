# 广告投放方案

## 适用场景
新品推广、大促备战、新市场测试、预算重新分配。

## 输入信息
- 目标市场、产品与客单价
- 月度广告预算与目标（ROAS、CPA 或 新客数）
- 毛利率、退货率（用于计算盈亏平衡 ROAS）

## 方案步骤
1. **盈亏平衡 ROAS** = 1 / 毛利率（扣除退款、物流等后）。目标 ROAS 必须高于此值。
2. **平台选择**：Google 搜索（主动需求）、Google/Meta/TikTok（兴趣与种草）、再营销（站内访客）。
3. **预算分配**：测试期约 20% 预算用于探索，80% 投向已验证渠道；按阶段递增。
4. **结构设计**：按产品线/人群/地域分广告系列；每组 3–5 套素材。
5. **素材规划**：前 3 秒钩子、卖点、CTA；竖版与方版素材各备一套。
6. **测试计划**：每次只改一个变量；设定最小测试周期（通常 7 天）与停止条件。

## 输出格式
```
## 盈亏平衡与目标 ROAS
## 渠道与预算分配表
## 广告结构图（系列 → 广告组 → 素材）
## 素材清单与文案方向
## 测试计划（变量、周期、成功/停止标准）
## 风险与预算保护规则
```

## 注意事项
- 平台政策、CPC/CPM 等市场数据随时变化，需提示用户以后台实际数据为准。
- 不承诺具体投放效果。
