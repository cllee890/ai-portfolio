# B2B 询盘回复

## 适用场景
外贸平台（如 Alibaba.com）、独立站表单或邮件收到的采购询盘；需要快速、专业地回复并推进成交。

## 输入信息
- 询盘原文（产品型号、数量、目标价、交付地、认证要求）
- 公司基本信息与可提供的产品目录
- 价格表（阶梯报价）、MOQ、交期、付款方式的内部政策
- 可提供的认证文件清单（如 CE、RoHS、ISO）

## 回复步骤
1. **判断询盘质量**：区分真实采购、信息收集与无效询盘，并给出优先级。
2. **确认关键信息**：数量、目标价、交付地、认证、包装与标签要求。缺失项在回复中提问。
3. **报价结构**：按数量阶梯列出单价、MOQ、交期、付款方式，并注明价格有效期与汇率条件。
4. **增信材料**：附上工厂与产品能力说明、认证文件清单，不提供未经核实的证书。
5. **样品政策**：说明样品是否收费、是否可抵扣订单、预计交期。
6. **推进动作**：提出一个明确的下一步（如确认规格、安排视频验厂、签订样品单）。

## 输出格式
```
## 询盘评估（真实度 | 优先级 | 缺失信息）
## 回复邮件草稿（英文，附中文译文）
## 报价表（数量阶梯 | 单价 | MOQ | 交期）
## 需内部确认的事项（价格、交期、认证有效性）
## 跟进计划（首次回复后 1 天、3 天、7 天）
```

## 注意事项
- 报价与交期需由内部审批后发出，草稿中以占位符标注，不得擅自承诺。
- 不提供虚假认证或夸大的产能数据。
- 注意反诈骗：要求异常预付款、代收代付或绕过平台交易的询盘应标记风险。
